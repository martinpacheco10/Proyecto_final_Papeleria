# Papeleria POS
Sistema de punto de venta de consola desarrollado en Java estándar para NetBeans.

**Integrantes:** Juan Jose Castillo y Martin Pacheco.

## Cómo abrir
1. En NetBeans selecciona Archivo > Abrir proyecto.
2. Selecciona la carpeta `PapeleriaPOS`.
3. Ejecuta la clase `ejecucion.Main`.

## Paquetes
- `modelo`: productos, clientes, ventas, ítems y medios de pago.
- `logica`: administración de productos, clientes e historial de ventas.
- `ejecucion`: menú de consola.

Los datos se mantienen en memoria durante la ejecución, tal como solicita la guía.
